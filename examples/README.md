# Synthetic demo inputs

These files are small, hand-authored examples for demonstrating the upload modes without using private data.

- `sample_sales.csv` — Spreadsheet mode. Example: **Which product generated the most revenue?**
- `sample_policy.pdf` — Documents mode. Example: **How many days of annual leave are provided?**
- `sample_handbook.docx` — Documents mode. Example: **When must expense claims be submitted?**
- `sample_briefing.pptx` — Documents mode. Example: **What is the main risk in the Q1 review?**
- `sample_invoices.csv` — Invoice mode. Example: **Which vendor received the highest total amount?**

All names and values are synthetic. These examples are demo fixtures, not evaluation evidence and not business-impact data.
